# thief macOS Reader Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** 交付可本地运行的 macOS `.app`：本地书架、TXT/EPUB 纯文字导入、菜单栏及悬浮阅读、章节跳转、外观设置与全局快捷键。

**Architecture:** Go 核心负责解析、持久化、阅读状态和分页边界；AppKit 经 cgo 负责界面、字体测量及系统集成。后台解析只通过消息回到主线程更新 UI；当前阅读位置按章节内 Unicode 偏移保存，不按页码保存。

**Tech Stack:** Go 稳定版、cgo、Objective-C/AppKit/CoreText/Carbon；标准库 archive/zip、encoding/xml、encoding/json、regexp；golang.org/x/net/html、golang.org/x/text。依赖首次安装时固定实际版本到 go.mod/go.sum，不预设未验证版本。

**Spec:** `docs/superpowers/specs/2026-11-20-thief-design.md`（已批准）。

## Global Constraints

- 仅支持 macOS；暂定最低 macOS 13。
- 用户选择 **Go + 少量 Objective-C 原生桥接**。
- 没有在线书籍、书源管理、账户、网络同步、小说编辑或 EPUB 导出。
- EPUB 不保留图片、CSS、字体和特殊文字样式；保留阅读顺序、可读文字、标题与段落。
- 所有 AppKit 操作在主线程；解析和磁盘操作在后台执行。
- 不通过整体窗口透明度同时改变背景和文字。
- 隐藏期间悬停和翻页不自动恢复正文；恢复必须通过恢复操作。
- 用户数据存于 `~/Library/Application Support/thief/`，不删除原始文件。
- 首版不要求 App Store、开发者签名证书、公证或自动更新。
- 当前机器 arm64、Xcode SDK 可用；未发现 Go。已有未跟踪 `.idea/`，不得提交或改动用户 IDE 文件。

## Review Focus

1. 异步导入结束时用户已切换书籍：不应强制切书或覆盖当前进度（任务 5）。
2. 长行、emoji 组合与 UTF-16 / Go 字符偏移转换：分页不得跳字或卡在零长度页（任务 4、6）。
3. 缺失文件、写盘失败或重启：不能悄悄清空书架（任务 3）。
4. 目录弹出或拖动过程中鼠标离开：不能收起正在操作的窗口（任务 7）。
5. 全局热键被占用或重设失败：保留旧绑定，明确显示错误（任务 8）。
