# thief：macOS 轻量小说阅读器设计

日期：2026-11-20  
状态：用户已于 2026-11-20 批准；设计与交互草图已完成，进入实现计划阶段。

## 目的与范围

在当前目录创建 thief，用 Go 开发一款仅支持 macOS 的本地小说阅读器。使用者希望在操作其他应用时，通过菜单栏或低干扰的悬浮区域阅读小说，能够迅速收起、隐藏和切换章节。

首版包含本地书架、TXT / EPUB 导入、章节目录、两种阅读模式、全局快捷键、外观设置与自动保存阅读位置。没有在线书籍、书源管理、账户、网络同步、小说编辑或 EPUB 导出。EPUB 不保留图片、CSS、字体和特殊文字样式；保留阅读顺序、可读文字、标题与段落。

反目标：阅读时抢占其他应用的输入焦点；调整字号或窗口大小后丢失位置；导入大书阻塞界面；把整部书拼成菜单栏文本；后台隐藏后被鼠标悬停意外恢复正文。

## 已确认的技术方案与备选方案

用户选择 **Go + 少量 Objective-C 原生桥接**。Go 负责书籍解析、章节识别、阅读状态、分页边界管理、书架和配置持久化；Objective-C 经 cgo 连接 AppKit，负责窗口、文本测量和呈现、菜单栏、鼠标跟踪、文件选择和全局快捷键。界面使用原生控件，不引入网页前端。

备选为 Go + Wails：方便构建复杂界面，但本项目主要交互依赖 macOS 原生能力，网页透明背景和特殊窗口仍需额外处理。另一种为纯 Swift / Objective-C 原生应用，但不符合用户指定使用 Go 的要求，因此不采用。

仅支持 macOS；暂定最低 macOS 13，优先在当前机器架构验证，保留构建 arm64 与 amd64 的能力。最低系统版本是本设计的建议，实际兼容范围以实现验证为准。分发产物为可本地运行的 `.app`；首版不要求 App Store、开发者签名证书、公证或自动更新。

## 页面与功能

### 书架窗口

应用提供正常的书架管理窗口，入口为“我的书架”和“设置”。关闭管理窗口后阅读与菜单栏继续运行，退出应用通过明确的退出操作。

书架展示书名、原始格式、当前章节与进度，提供本地导入、书名搜索、继续阅读。书籍使用文字封面，无需提取 EPUB 图片。单本书的右键菜单重点提供“章节列表”和“继续阅读”；同时提供可直接点击的章节入口。

补充的实现决定：提供“从书架移除”，只删除应用内部书籍副本和阅读进度，不删除原始文件。首版不做分类、自定义封面或修改来源路径。导入后阅读不依赖原文件路径。

### 章节列表

从书籍右键菜单或章节按钮打开对应书的章节列表。显示书名、章节总数、当前章标记，支持按标题或章节序号搜索。点击章节从该章正文开头开始，在当前阅读模式中展示，关闭目录及管理窗口，回到此前工作的应用；恢复工作应用焦点需在原生集成中验证。

列表打开时定位当前章节；卷作为分组呈现，含正文的卷内容仍可阅读，不丢弃。大量章节使用原生可复用列表，不一次创建数千个独立视图。菜单栏图标/文字的右键菜单、悬浮区右键菜单也提供当前书“章节列表”和“打开书架”，方便阅读时访问。

### 设置

所有设置集中在书架管理窗口中的设置页面，可即时预览并保存：

- 阅读模式：菜单栏 / 悬浮区域。
- 悬浮区域宽、高及位置；支持数值设置、拖动区域位置、拖拽边缘调整尺寸，随本文批准纳入范围。
- 区域背景颜色、背景透明度。
- 文字大小、颜色、透明度；行距。
- 鼠标移出自动收起开关、收起延迟（建议默认 400 毫秒）。
- 菜单栏文字宽度（以系统点为单位）、菜单栏字号。
- 全局快捷键修改、启用状态和冲突反馈。

背景与文字颜色都提供颜色选择器及 `#RRGGBB` 输入框，双向同步；输入大小写均接受。无效值在字段旁提示，不替换上一次有效颜色。透明度单独保存：0% 完全可见，100% 完全透明。不通过整体窗口透明度同时改变背景和文字。区域外观设置作用于悬浮区域；菜单栏背景沿用系统样式，文字默认使用系统自适应颜色。

悬浮区默认建议：355 × 236 点、字号 16 点、背景 #F5F3EB、背景透明度 14%、文字 #343B43、文字透明度 0%。字号、区域宽高必须有合理下限，不能出现零宽高或零字号；最终上下限交由实现者根据可读性确定，并限制在当前屏幕可用区域。文字全透明时仍可通过管理窗口恢复设置。

## 阅读交互

### 菜单栏阅读

小说正文直接显示在系统顶部菜单栏的状态项目中，而非点击图标才展示。每次显示一个能完整容纳的文本片段；通过快捷键或菜单前后翻段。这里的“页”指菜单栏可容纳的一段文字，不是整章，也不自动滚动。按实际字体测量，避免截断导致文字被跳过。

菜单栏宽度由用户设置；受系统可用空间限制，刘海、其他状态项目和当前应用菜单可能影响可见性。首版不承诺固定位置或始终获得指定宽度；通过设置减小宽度或切换悬浮模式处理。菜单栏模式默认不同时显示悬浮正文。

### 悬浮阅读

正文以无普通标题栏的悬浮面板呈现，在其他普通窗口上方。阅读展示及鼠标悬停不激活应用、不打断其他应用键盘输入；管理窗口、目录和设置可以正常获得焦点。

鼠标移出展开区域后，等待默认 400 毫秒，缩成锚定在原区域右上角的小图标；移入图标立即恢复原位置、原大小。只有可见图标触发恢复，原区域空白位置不触发。收起后取消旧区域鼠标跟踪，恢复后重新建立跟踪。进入右键菜单、拖动、调整尺寸期间暂缓收起；操作结束重新判断鼠标位置。用户可关闭自动收起来固定显示正文。

面板支持分页，正文不溢出边界；显示当前章节、轻量进度与翻页操作。区域或字号变化后重新分页，当前阅读锚点保持不变。整章、整本书的开头/结尾有明确边界，不能翻到空白或无效页。

全屏应用、多个 Space、多显示器上的窗口层级及跟随行为需在原生实现中验证；建议面板跟随用户所在 Space，保存屏幕信息，屏幕断开时把区域移回可用屏幕。首版不承诺盖住系统安全界面或系统菜单。

### 全局快捷键与隐藏状态

用户已确认：在其他应用中也可翻页、切章、隐藏，不必切换到 thief。建议默认：

| 操作 | 默认快捷键 |
| --- | --- |
| 上一页 / 下一页 | Control + Option + Left / Right |
| 上一章 / 下一章 | Control + Option + Up / Down |
| 隐藏 / 恢复 | Control + Option + H |
| 切换阅读模式 | Control + Option + M |

优先使用系统全局热键注册机制，避免监听全部键盘输入。注册失败或快捷键冲突时给出具体反馈，保留菜单操作作为替代；不得静默显示为已启用。最终系统 API 和权限需求留给实现者验证，若系统确需用户授权，提供实际需要的说明。

一键隐藏会清除菜单栏正文并隐藏悬浮正文及收起图标，保留中性菜单栏图标用于恢复；不会改变阅读位置。隐藏期间悬停和翻页不自动恢复正文；恢复必须通过恢复操作。模式切换保留隐藏状态。收起、隐藏、管理窗口关闭是独立状态。

跨章节翻页：章节末尾“下一页”进入下一可读章节开头；章首“上一页”进入上一可读章节末页。上一章/下一章始终跳到目标章开头。章节目录可访问任何章节。全书边界停在当前位置，不循环。

## 导入与章节识别

### TXT

参考本地 EPUB Studio 的实际实现：

- `/Users/eastwood-mac/Code/RustroverProjects/epub/src-tauri/src/txt.rs`
- `/Users/eastwood-mac/Code/RustroverProjects/epub/src-tauri/tests/txt.rs`

移植其识别思路与关键验证案例到 Go：支持“第<number>章/节/回/集”、卷/部/篇，常用中文数字及大写数字、阿拉伯数字；支持“1、标题”、英文 Chapter 与罗马数字、序章、楔子、引子、尾声、后记、番外、终章。章节标题只在段落边界识别，结合长度、标点和引用形式排除普通正文。保留前言；无章节的文本作为一个可读章节。规范 BOM、换行，处理固定宽度硬折行并保留段落边界。

保留章节和卷的可选自定义正则，放在导入的高级选项中；检查无效正则及匹配空串的模式。参考项目只读取 UTF-8，本项目建议额外支持 UTF-8 BOM、UTF-16 BOM、GB18030（包含常见 GBK）。无 BOM 时先验证 UTF-8，否则尝试 GB18030；若无法可靠解码，明确报错并允许手动选择编码，不静默吞字。

### EPUB

按 container → OPF manifest / spine 确定正文顺序；目录优先读取 EPUB 3 nav 或 EPUB 2 NCX，结合文档内标题和锚点形成章节。不能仅凭 ZIP 文件名排序，或假设一个 XHTML 必然只有一个章节。目录缺失时按 spine 文档及正文标题回退；没有明确章节时仍保留可读正文。

使用结构化 HTML/XML 解析提取正文，保留块级段落、换行、HTML 实体文字，忽略 script/style、图片等不可读内容。不执行内容脚本，不加载远程资源。纯图片且无文字的书明确报告无可读文本。加密正文、损坏归档或不支持的 DRM 内容给出明确错误。

导入在后台完成，完成后原子更新书架；失败不留半本书。重复导入相同文件按内容摘要识别并提示已有书籍，不清空已有阅读位置。对压缩展开量和异常路径设界限，不解压到任意外部目录。具体安全界限由实现者确定并记录。

## 数据与架构

采用 Go 核心与 AppKit 桥接分层。所有 AppKit 操作在主线程；解析和磁盘操作在后台执行，通过明确的事件/命令更新界面。cgo 回调避免跨线程直接修改原生控件；对象、缓冲区和字符串所有权需明确。

首版建议不引入数据库：用户数据存于 `~/Library/Application Support/thief/`，包含原子写入的书架索引、全局设置和每本书的章节文本及阅读状态。导入结果保存为应用内部纯文字副本，不依赖源文件，不保存 EPUB 图片和样式。书架索引只加载元数据，阅读时加载当前书，避免启动加载全部正文。最终文件组织与版本迁移由实现者决定。

阅读位置保存为章节标识 + 章节内 Unicode 文本偏移，必要时规范为字素簇边界，不能只保存页码。分页属于当前布局的派生数据：菜单栏与悬浮区各按实际可用尺寸测量，切换模式或修改外观时从同一锚点重新布局，确保不跳字、不重复丢段。上一页需要可追溯到包含前一锚点的页面边界。

翻页、切章、切书、退出时保存位置；外观及拖动设置采用短延迟合并写入与原子替换。普通退出前刷新未落盘状态；异常退出允许极短的合并写入窗口损失，不能损坏整份书架。默认重启后恢复最近书籍与位置，但以中性图标状态启动，用户主动恢复正文，避免自动暴露小说。

## 验证与验收

- Go 解析测试覆盖参考项目的主要章节案例、正文误判、前言、卷、硬折行、自定义规则及编码。
- EPUB 覆盖 spine 顺序、EPUB 2/3 目录、单文档多个章节、实体、去图片样式、无目录、纯图片、损坏/加密输入。
- 阅读核心验证 Unicode 边界、分页前后连续性、跨章、尺寸字号变化、模式切换及进度恢复。
- 验证设置和书架原子持久化、重复导入及失败恢复。
- 本机实际运行 `.app` 验证菜单栏正文、全局快捷键、不抢焦点、鼠标收起恢复、拖动调整大小、独立透明度和十六进制输入、书架右键目录跳转。
- 验证一键隐藏后鼠标不会恢复；管理窗口关闭后仍能阅读；重启可恢复位置。
- 原生多屏、全屏、Space 行为据实际测试记录，不用 Go 单元测试替代 UI 验证。
